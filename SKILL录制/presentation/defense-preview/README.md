# 课题答辩 · 前三页预览

打开 `index.html`，或打开 `docs/课题答辩-前三页预览.html` 单文件版本。全部资源本地内置，无需安装依赖或连接网络。

- ← / → / 空格：翻页
- F：全屏
- O：缩略图总览
- N：讲述提示
- S：演讲者视图
- 鼠标移动时显示底部翻页按钮

## 内容映射

唯一内容依据：`docs/课题答辩材料提纲.md`。

1. 封面：提纲标题及第 0 节的研究主张。
2. 核心主张：第 0 节，描述式与演示式输入对比，以及“大处着眼，小处着手”。未经填写的典型耗时未作为数字上屏。
3. 问题的发现：第 1.1 节，严格按“场景 → 卡点 → 顿悟”叙述。具体工作、说明耗时、尝试次数、错误表现、操作耗时保留待补。

仅制作三页供确认，未继续后续章节。

## 设计与来源

1600 × 900（16:9），白底、科技蓝、淡蓝辅助区、系统中文字体。自适应缩放。

基于 html-ppt 的 cover、comparison、process-steps 模板。base.css 与 runtime.js 来自 html-ppt（MIT，Copyright 2026 lewis），运行时的预览设计尺寸调整为 1600 × 900。

`assets/tech-blue.css` 为本稿主题与排版；`assets/deck.js` 提供缩放与点击导航。`previews/` 保存实际浏览器截图。
