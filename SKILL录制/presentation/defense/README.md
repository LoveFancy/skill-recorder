# 课题答辩 · 16 页 HTML 演示文稿

入口：`docs/课题答辩.html`（单文件，样式与脚本内置，可离线打开、复制与分享）。

开发入口：本目录的 `index.html`。唯一内容依据：`docs/课题答辩-逐页稿.md`（2026-10-19 版）。

## 操作

- ← / → / 空格：翻页；Home / End：首尾页
- F：全屏；O：页面总览；N：本页讲稿与完整逐页稿；S：独立演讲者视图
- 移动鼠标：显示底部控制条
- 点击截图位：选择真实脱敏 PNG / JPG / WebP 图片；填入后点击可放大查看或更换
- 点击底部 ↓：保存包含已填图片的完整 HTML（请使用单文件入口）
- 浏览器打印：按 16:9 页面逐页打印，保留背景色

图片仅在当前页面内存中处理，不上传；填图后应保存 HTML，刷新未保存页面会丢失新增图片。请在填入前完成脱敏与重点红框标注。

## 内容与边界

完整保留 16 页顺序，压缩上屏文字，将原文讲稿、完整逐页稿、答辩追问放入隐藏备注。

15 个证据位均已落页：P3（1–2）、P5（3–4）、P8（5）、P9（6）、P10（7–10）、P11（11）、P12（12–13）、P15（14–15）。第 11 位采用原稿允许的“设计示意”；其余 14 位保留真实脱敏截图占位，没有把线框图冒充实物截图。具体内容见 `待补素材清单.md`。

待补的业务数据与实测分数没有编造；P2 的耗时对比按原文“有数据才上”暂不上屏。机制五、独立文档导出、实际业务试运行等实现状态均依逐页稿标明，没有扩大已实现范围。

## 设计

1600 × 900 / 16:9。白底、科技蓝、深蓝强调条。无远程字体或外部运行依赖。

基于 html-ppt 的 cover、comparison、flow-diagram、table 模板与基础运行时（MIT，Copyright 2026 lewis）。运行时调整：预览尺寸 1600 × 900；页码只更新当前页，避免打印其他页时页码串位。

`assets/theme.css`：本稿主题与布局；`assets/deck.js`：缩放、导航、截图填入与保存。

重新生成单文件：`python3 docs/presentation/defense/build.py`。若已在浏览器填入实物截图，请保存为另一个文件，避免重新构建覆盖。
