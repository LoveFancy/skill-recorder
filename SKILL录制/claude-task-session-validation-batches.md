日期：2026-10-15。范围：本机 macOS、Claude Code 2.1.251、合成输入、本机回环模拟模型。承接 [初次验证报告](claude-task-session-design-verification.md) 的四个 P0 与六项验收门槛。

本轮按批次独立验证，共用原脚手架的 HTTP/SSE、确定性工具调用和隔离目录方法，没有替换验证方法论。产出的是设计和机制证据；没有将原型接入产品，也没有修改原设计正文替用户作最终架构决策。

| 原生恢复 | `agent-session-resume.ts` | 模型/cwd/对话游标校验；原生恢复与跳过历史绑定；普通失败恢复与策略锁定区分 | run/attempt/config/policy 修订绑定、取消后的副作用不确定性、损坏历史 |

OpenDesign 默认的 Claude 授权姿态是 bypassPermissions。其“受管资源目录”或名为 sandbox 的目录重定向不能直接视为本项目的 OS 安全边界。借用代码与职责应优先于新增抽象，但每条只读承诺都要落到实际执行入口。

## 2. 独立派发合同

每批交付相同的最小材料：固定 CLI 版本、完整 argv/环境来源、前置数据、正/负对照、明确通过标准、模型请求与工具结果、实际文件/后端副作用、未测边界、复现脚本和证据路径。

状态区分：

- **CLI 单项通过**：实测符合该例期望，不外推全部组合。
- **原型通过**：候选代理、回收器或 guard 机制有效，尚未接入产品。
- **产品通过**：必须由真实产品入口复跑；本轮不以原型冒充。
- **不通过**：有具体反例；正常退出或模型自报完成不改变判定。
- **未验证**：没有执行环境、未运行或前置条件不成立，不能计入通过。

A、B、D、E、F 的机制测试可独立运行。C2 依赖 B3 代理策略，最终 F 的 MCP 证据采集也依赖产品受控调用入口。总体按 A→B→C→D→E→F 收敛，而不是宣称所有集成验收完全无依赖。脚手架副本与端口、临时 HOME/config、合成标记分别独立，避免互相覆盖。

## 4. G 的独立派发说明

### G1：真实模型 Skill 选择质量

前置条件：A 的配置来源与 Skill 路径选择已确定，B/C 的权限已收敛；使用合成任务、无业务 MCP。固定模型 ID、CLI 版本、任务插件修订和工具集合，设置运行预算。真实模型调用另外记录成本与耗时，不使用实际录制材料作为这项验证的输入。

至少区分以下用例：

| 用例 | 操作 | 通过/不通过标准 |
|---|---|---|
| G1-explicit | 提供完整插件 Skill 名及足够任务材料，显式要求调用 | 实际 Skill tool_use 命中目标且后续请求有技能正文；缺少调用或目标错误为不通过 |
| G1-autonomous | 不写调用指令，仅提供与 Skill 描述一致的合成任务和足够上下文 | 实际自主选择目标 Skill，并遵循可观察的步骤契约；只在回答中说“使用技能”不算通过 |
| G1-negative | 提供不相关任务 | 不误触发目标 Skill；出现无理由调用记不通过 |
| G1-namespace | 两个插件含相同裸 Skill 名，任务指定其中一个 | 实际调用正确全名，不依赖歧义裸名称猜测 |

一次成功只证明该例可行；若要报告稳定性，预先固定重复次数与统计口径，保留每次结果，不能失败后改阈值。G1 是质量证据，不替代 CLI 机制测试。

### G2：Windows 与支持范围

在真正的 Windows 环境复跑 A/B/C 的隔离与副作用用例；路径含空格、非 ASCII、盘符及实际支持的启动器类型。D 使用 Windows 适用的进程树/Job Object 机制，测试后代、忽略终止、重启恢复与身份冲突，不能把 POSIX 负 PGID 操作当实现。

通过标准与本机相同：合法读可用、越权写无副作用、被取消的运行及其后代退出、无关进程不被杀。无执行环境就标未验证。若首次上线只评审 macOS，可延后 Windows 结论；若首次上线对外宣称支持 Windows，相应权限与回收门槛不能以本机通过替代。

## 5. 汇总后的正文改写边界

本轮保留原始提案正文，供用户根据新证据统一改写。改写时优先继承 OpenDesign 已有的运行时定义、提示词组合、事件解析、身份记录及原生恢复策略，再叠加本项目必须具备的只读授权、环境筛选与证据保全。

不能继续保留“空 config 等于完整隔离”“add-dir 是只读”“tools 能过滤全部 MCP”“PID 存活即可回收”“事件脱敏会自动覆盖原生会话历史”等已被反例推翻的承诺。每个原型通过项还需要通过真实产品入口的集成验收，才能关闭对应 P0。
