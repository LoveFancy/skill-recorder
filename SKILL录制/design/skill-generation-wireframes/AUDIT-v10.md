# v10 全量设计核对

日期：2026-10-15。范围：47 个状态、交互索引、所有单图、全部总览及 ZIP。仅更新设计文档。

| 发现的问题 | 调整 |
| --- | --- |
| 新增目标确认页在目录末尾，阅读顺序脱离实际操作 | 前置目标/语音/核对，再接录制和分析；设置/恢复独立分组 |
| 总览还是旧截图，第二阶段名称不统一 | 更新全部总览，统一“澄清和补充” |
| “任务包”对用户过于技术化 | 改成“确认补充内容”，保留内部文件 ID |
| 残留销售项目/关联项目表述 | 新任务统一专用环境；历史项目仅追溯 |
| 初判手动触发与首次进入自动触发混写 | 设计统一首次进入自动一次，有效结果复用；失败/取消/修订显式处理 |
| 正常环境卡太重 | 状态缩为一行，异常按需展开 |
| 补证旧图显示自动查邮箱，超出实现边界 | 自动只处理已有材料；外部证据明确人工导入，不把 MCP 启用等于授权 |
| 追加澄清问技术证据或历史邮件选择 | 改为必要业务规则冲突，不替用户推断 |
| SOP 目标没有对应输出终点 | 增加 SOP Markdown 预览与导出完成，明确是待实施设计 |
| 目标期望可能被写成实际发生 | 用户目标、模型分析、观测证据独立，差异保留，版本引用贯穿 |
| 录制目标修改跳回新建录制 | 修订页只保存目标，不启动录制；语音新建流程与修订上下文分开 |
| 截图内不可见旧右侧内容仍残留 | 清理被裁剪的嵌套内容，避免检索和跳转误读 |

核验：SVG XML 可解析；47 个唯一 ID 与文件一一对应；所有 data-screen 跳转目标有效；manifest 顺序与 HTML 相同；单图/总览 PNG 全量重渲染；ZIP 同步重建。

未声称完成：应用问卷/自动触发/录制前意图/SOP 导出实现、真实点击验收、业务执行测试。设计中尚待实施部分以本版 README 和主方案说明为准。
