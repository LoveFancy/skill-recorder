## 一致的交互规则

### 录制目标

点击录制先确认想产出什么（SOP / Skill / 其他）、希望完成的任务。至少提供一段目标说明，不要求完整方案；示例不自动代填。不单独询问最终效果，不显示业务范围补充及证据说明文案。文字与语音均可输入，目标语音显式启动、停止转写、用户核对后采用，此时尚未采集屏幕。语音不可用保留文字入口，采用不静默覆盖原输入。

目标确认后执行原有录制权限检查，失败保留目标。原音频默认临时处理，保存用户确认文字；取消/采用后清理策略需实施。目标与观测证据分开保存，Analysis.intent 的模型推断不能替代用户目标。分析、澄清、生成都引用目标版本。

旧录制可补填目标；修订保存新版本，不启动新录制、不删除旧回答。已有分析/问题/生成结果按版本提示更新，用户决定是否重跑。

### 分析与澄清

原始录屏、截图、语音、浏览器事件的理解发生在基础分析。进入第二阶段首次自动整理一次，输入为用户确认目标、前序分析和已有补充；返回页面复用有效结果，不重复调用。目标或分析改变需确认更新；失败/取消后通过明确操作重试。

显示真实可观测阶段：检查环境 → 读取目标和分析 → 模型整理问题 → 校验并展示。显示实际后端与耗时，不虚构百分比、模型思维链或单次调用内部进度。配置失败就地显示原因；配置修复后显式继续，避免设置变更自动启动任务。

默认优先本地 Claude；未安装且策略为自动时才回退 API，用户也可主动选 API。登录异常不静默回退。API 页面不能显示本地 MCP/Skills 已加载。

只问目标、业务规则、例外、输出要求；不问红框解释、技术配置或让用户替系统识别截图。问卷按“问题 1、问题 2…”编号，有依据时给单选项；不默认代选，选择“其他”展开输入。未知/跳过不是已回答，不假定为规则；计数只包括选中业务选项或非空自定义回答。适用范围及参考材料按需展开。

### 确认与补充处理

“确认补充内容”汇总已有分析、用户回答、材料和剩余缺口；确认之后才启动后续补充处理。自动处理只使用已有材料和受控的 Skill 参考资源，当前不自动查询邮箱或其他业务 MCP。需要外部证据时导出脱敏材料、用户手工处理并导入，进入同一审核流程；页面明确证据来源。

追加问题只针对新业务冲突，保留回答，确认新版本后继续。模型结果都是候选，审核不因导航、导入成功或模型自报而自动批准。未回答关键问题可保留缺口导出草稿，不伪装完整结果。

### 生成与输出

录制前的产出偏好传入生成，但用户可以明确修改。SOP 进入 Markdown 文档预览/导出；Skill 进入目标选择、计划、预览/导出。两者均标记未核验的内容，不宣称已执行。SOP 导出是新增设计，当前代码尚未提供独立实现。

Scout 等既有目标可见，但不扩展 Scout 导入、Replay、Computer Use、执行器、自动安装或业务试跑。通用 Skill 不直接继承本地专属工具，缺少可移植接口须保留依赖缺口。

### 布局和设置

环境状态缩为一行，正常不显示大卡片；只有异常才展开原因和修复入口。阶段导航固定、正文独立滚动，问卷不套第二层滚动列表。设置与异常放在目录后半段，不插断主流程。

设置为独立窗口，分类为通用、浏览器插件、AI 模型、Agent 能力、语音转写、隐私保护。各组显式保存，未保存离开提示，失败保留输入。首页只显示状态和统一设置入口。配置检查、保存、主动 MCP 连接检查分别执行。

Claude 自动专用环境取代新任务的项目目录关联，不修改全局原配置。新能力默认关闭；来源变化待复核，移除/冲突禁用。所选 Skill 为受控文本参考，不是工具；MCP 开关不授予业务权限。任务固定配置版本，历史项目仅作追溯。
