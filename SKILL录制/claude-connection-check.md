# 分析前连接自检

Claude 后端每次准备新任务（包括重试）时，在规划和读取录制材料前执行自检。

先通过现有配置检查确认 CLI、隔离接口和登录状态可用，再使用分析所用的全局连接配置、专用工作目录和受控 CLI 调用链，发送不含录制材料、Skill 内容的最小结构化请求。只有模型调用 `submit_connection_check` 并提交 `{ "ok": true }` 才算通过；进程启动或会话初始化不代表通过。

自检最长 30 秒，支持停止。失败后不调用规划模型，显示失败原因；重试重新执行自检。直接 API 后端不执行 Claude 自检。

轻量 CLI 请求的诊断日志位于应用数据目录 `processing/logs/claude-*.jsonl`；深度分析日志位于对应任务的控制目录 `execution.jsonl`。日志只记录进程、事件类型、等待、超时和退出等元数据，不记录提示词、思考内容、工具参数或认证令牌。

## 输出额度

Claude 轻量请求与深度分析共用 `electron/agents/process.ts` 中的 `CLAUDE_OUTPUT_LIMITS`：累计标准输出 256 MiB，保留的完整消息及最终结果合计 64 MiB，单条消息最多 64 MiB。普通进程默认标准输出上限为 64 MiB。

流式增量及高频系统状态实时传给进度处理器，随后丢弃，不计入保留额度。完整工具调用、工具结果、初始化和最终结果仍保留供证据提取及结果解析；完整 assistant 消息中的思考块不保留。高频事件只记录汇总数量，诊断日志在等待和退出时记录原始字节数、保留字节数及高频事件数。累计输出、保留额度或单条消息超限仍会终止进程。
