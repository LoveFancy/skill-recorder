# Skill Recorder 交互线稿 v11.2

面向非技术用户：**原始素材确认 → 深度分析 → 生成**。本次仅更新设计，不修改应用。

[打开交互线稿](index.html) · [三步对照](v11/board-three-stages.png) · [主流程总览](v11/board-main.png) · [交互规则](REVIEW-v11.md) · [状态目录](ORDER.md) · [下载 ZIP](../skill-generation-wireframes.zip)

1. **原始素材确认**：核对录制中的操作，纠正识别错误。素材默认折叠，展开查看语音、截图和浏览器三行时间线。
2. **深度分析**：结合用户意图、原始操作和实际可用工具补充细节，必要时提出业务问题。回答后整理成完整、可编辑的分析结果，用户点击“确认并生成”后才进入下一步。
3. **生成**：依据已确认结果生成 Skill / SOP，预览、修改并保存。实际使用依赖按需查看，不声称已经运行验证。

第二阶段只有一个一级导航，处理中、必要提问、分析结果属于同一阶段的状态。没有问题直接展示分析结果；不确定的内容保留提醒，可确认后生成带缺口的草稿。

每页围绕一个主要动作。分析结果以流程正文为主，工具与来源按需展开；不展示任务包、快照等内部概念。每一步均可返回修改、显式重新处理；上游变化保留回答和旧成果，标记受影响内容需要更新。回看不自动调用 Agent。

录制页保留现有竖向布局，录制前只收集产出类型及一句话目标，语音入口在输入框内。技术配置仍集中在独立设置页。

索引展示 11 张主路径示意，等待态自动转换；其他状态和设置默认折叠，不是额外必经步骤。图中数据与操作均为演示。

线稿源文件位于 `v11/generate.py`；运行后生成 SVG、索引、清单和总览，再使用项目已有 sharp 渲染 PNG。历史 v10 文件仅作对照。

深度分析等待态采用左右布局：左侧统一列出实际使用的工具和素材，右侧根据 Claude 结构化进度 JSON 逐条更新动态时间轴，应用补充实际运行和调用异常；模型报告与工具核验记录分开。工具名称只出现一次，不在每个工具卡片中重复过程。时间轴展示动作、状态和简短结果，不展示思维链；长记录内部滚动，回看不强制跳到底部。
