SOP 一键生成；使用手册的读者/范围输入、确认框和正文编辑可操作。选择顶部预览状态可检查所有分支。常用路径为 01 → 03 → 05 → 08 → 11 → 12，手册路径为 02 → 03 → 04 → 05。03/11 的“演示：处理完成”仅是审稿控制，产品中由真实执行结果推进。

发布页的所有账号、目录、权限、时间、内容与链接都是合成示例。`example.invalid` 不指向服务。不会发起模型请求、授权请求、上传、通知或真实发布。文件保存、远端打开、链接停用等操作用提示模拟；更新已有发布的差异预览与确认规则见方案正文，尚未做成完整交互。

## 实施前需要确认的接口

1. 飞书授权与文档/截图上传适配；知识库节点创建需要单独权限和空间能力验证。
2. Wiki 首个适配器选飞书知识库；Confluence 等目标在适配完成前禁用。
3. SkillHub 具体服务的上传、审核、版本与安装接口；Workmate 插件安装格式、包托管、工作区可见性及链接停用能力。未具备则显示“待接入”，提供本地导出，不生成假链接。
4. 各渠道发布记录、幂等与远端核对机制；目标能力不支持幂等时，以客户端请求记录和远端对账限制重复创建，不承诺无条件 exactly-once。

主界面不暴露这些内部字段；技术说明只保留在设计文档和按需详情中。

## 最新渠道分流约定

SOP 与使用手册只展示飞书云文档、Wiki 知识库（包含飞书知识库）；Skill 只展示 SkillHub、Workmate。其他平台由对应类别的适配器扩展。此约定取代旧稿的文档 Workmate 资源包方案。切换产物会清除目标与发布确认，不重新生成内容。交互稿中的账号及已连接状态仍全部为合成示例，正式发布接口尚未实施。

## Skill 执行准备交互补充

[技能执行准备](../index-v12.html#skill)默认出现在 Skill 结果正文前，逐项列出必需/可选的 MCP、其他 Skill 与环境条件，说明用途、对应步骤、准备状态与权限；点击“查看准备说明”就地展开，不新增计划审核步骤。SkillHub/Workmate 发布摘要保留同一依赖清单，SOP/手册不展示这组执行依赖。具体规则见方案 §11.9；本轮仅补充交互设计，结构化依赖提取、核验与产品组件尚未实施。
